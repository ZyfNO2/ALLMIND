# 角色配置与图谱交互验证

本轮针对空白用户的管理界面操作。保留用户提供的 Companion Studio 视觉风格，修改操作顺序、入口、编辑和反馈，不重做模型协议或知识事实。

## 新用户路径

首页准备步骤 → 角色页新增/修改角色 → 核心人设或角色包导入 → 配置模型 → 测试 → 明确保存 → 开始对话。

- 新角色创建后自动选中并关闭管理弹窗。名称、介绍和核心人设有直接编辑入口。
- 核心人设逐条保留原有元数据；保存校验启用条目的合计 4 KiB 预算，取消保留原值。未保存编辑离开时提示。
- 文件选择仅预览，显示当前目标角色和冲突，确认后才应用。取消不写入；迟到结果不转写另一角色。
- 外观、关系、知情范围和维护项按需展开。原高级导入导出仍可使用。
- API 主要表单直接显示 Endpoint、Key、模型；名称和低频参数放入高级设置。获取模型、连接测试和保存各自独立；失败不清输入，测试不保存。保存后提供聊天入口。
- 原 ChatGPT 网页登录、High 核实与未知结果恢复约束保留；本轮没有新的真实网页验收。

## 图谱实现与边界

- Graphology 构图，ForceAtlas2 二维布局，Louvain 连接社区，Sigma 3 WebGL 渲染。布局计算在 Worker；单文件静态资源白名单支持带点的 Worker 文件名，仍拒绝路径穿越和非白名单后缀。
- 四类知识配色保留，可切换社区配色；节点大小随连接度变化。语义边带箭头，来源边较淡；社区和坐标只服务显示，不生成知识事实。
- 密集场景按实测文字宽度控制标签密度，选中和邻居突出；增加布局碰撞间距，避免节点点击区域遮挡。
- 搜索、节点目录、拖动、缩放、适应画布、全屏、Escape 返回、键盘焦点与侧栏证据检查保留。全屏期间限制 Tab 在图谱内，关闭后恢复焦点。
- 仍有 128 节点 / 2048 边上限，超出明确提示。所有节点为圆形；详细节点类型在侧栏查看。来源连线为浅色细线，不是旧 SVG 的虚线。
- 布局参考 LLM Wiki 公开实现的技术路线，独立实现适配；四类知识、角色知情范围和有据关系继续使用 ALLMIND 数据。
